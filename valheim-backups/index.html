Valheim Backups

A personal backup tool for the owner's Valheim game server. It uploads game-save archives to the owner's Google Drive and checks their contents before recording a successful backup.

Google Drive access

The owner signs in through Google and authorizes the drive.file permission. The tool creates its own backup folder and can manage files created by, or explicitly shared with, this application. It does not request access to the entire Drive.

This application is for the owner's personal use. It does not provide public registration, advertising or analytics.
